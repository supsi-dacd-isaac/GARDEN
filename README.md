# GARDEN

Grid-Aware Decarbonization of electricity-driven Neighbourhoods.

This repository is centered on three main components:

1. **Fast control strategies for batteries** (`battery_sizing_cfa`)  
   Methods for battery sizing and operation, including rule-based and optimization-driven control strategies for peak shaving and cost-aware operation.

2. **Neural emulator** (`neural_building_emulator`)  
   Neural thermal and heat-pump emulation models used to reproduce building dynamics with lightweight, data-driven surrogates.

3. **Flexibility KPI regressors** (`flexibility_estimators`)  
   Pipelines to estimate flexibility KPIs from simulation data and regress those KPIs against building/asset metadata.
